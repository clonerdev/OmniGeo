# OmniGeo v1.0.0

**Live 3D Geo-Locator, System VPN Fingerprint & Locale Sync, and Split Tunneling extension for Google Chrome and Mozilla Firefox.**

افزونه **OmniGeo** نسخه **۱.۰.۰** برای نمایش زنده موقعیت مکانی روی کره زمین سه‌بعدی، هماهنگی موقعیت جغرافیایی (GPS)، منطقه زمانی، زبان و محافظت ضد اثر انگشت با **VPN سیستم** (یا پراکسی مستقیم مرورگر) و مدیریت **تفکیک سایت‌ها (Split Tunneling)** در **کروم** و **فایرفاکس**.

## ✨ Features / امکانات اصلی

* **System VPN Mode (Default):** Works seamlessly alongside your active system-level VPN/proxy without requiring external desktop binaries or registry edits.
* **Direct Browser Proxy Option:** Optional support for direct `SOCKS5`, `HTTP`, and `HTTPS` browser proxy configuration.
* **Interactive 3D Globe & Country Picker:** Live location indicator with a country/city selector and flag icons.
* **Geo & Locale Synchronization:** Syncs Geolocation coordinates, Timezone, and `Accept-Language` / `navigator.language` with the selected destination.
* **Anti-Fingerprinting & Privacy:** Includes WebRTC leak protection, Canvas/Audio/WebGL masking, tracker blocking, and session data cleanup.
* **Split Tunneling & Iran Rules:** Route all sites except a bypass list, or only route an include list, with built-in/imported Iranian domain rules support.
* **Bilingual & Theme Support:** Persian (`RTL`) and English (`LTR`) UI with Light and Dark themes.

## 🚀 Installation Guide / راهنمای نصب

### 1. Google Chrome (کروم)
1. Download and extract **`OmniGeo_Chrome.zip`** into a folder.
2. Open Chrome and go to `chrome://extensions`.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select the extracted **`OmniGeo_Chrome`** folder.

### 2. Mozilla Firefox (موزیلا فایرفاکس)
1. Download and extract **`OmniGeo_Firefox.zip`** into a folder.
2. Open Firefox and go to `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on...** and select `manifest.json` inside the **`OmniGeo_Firefox`** folder.
